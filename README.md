# Capivara Radio Server V1
Servidor central inicial ADM ↔ Player.

Render:
- Runtime: Node
- Build: npm install
- Start: npm start
- Health: /health

Esta V1 cria a ponte e endpoints de clientes, configurações, estado, playlists, vinhetas e fundos.
IMPORTANTE: o armazenamento em arquivo do Render é provisório. Antes do uso real com clientes, conectaremos banco persistente e armazenamento de áudio.
